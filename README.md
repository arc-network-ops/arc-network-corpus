# The ARC V1 Corpus

This folder is the shared source of truth for the ARC Network as of Version 1. It holds the network specification and every document the specification lists or references — nothing else. If a document here disagrees with the specification, the specification governs. If anything anywhere else disagrees with this folder, this folder governs.

Assembled 2026-07-29 from the working corpus, under the decisions recorded in `Refactor Decisions — Daniel — 2026-07-17.md` (Parts 4–7, D21–D43). The working corpus remains the workspace; this folder is what ships.

## Status conventions

- **proposal — direction, not commitment**: the Coordination documents besides the Weekly Weave. They paint the shape of what might be built. The Weekly Weave is the only live technical system.
- **snapshot / pointer**: the two Logos Center nodes and the Logos pointer. The public Logos Text at publish.obsidian.md/logos-text always governs; snapshots refresh from it.
